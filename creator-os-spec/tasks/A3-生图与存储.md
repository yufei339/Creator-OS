# A3 · 生图接口 + R2 存储

## 目标
调用生图 API 生成图片,存到 R2,并把记录挂到脚本下。

## 前置
- A2 已通过验收
- 用户已在 .env 填好 R2 配置和 IMAGE_API_KEY

## 要做的事
1. 建 ORM 模型 `images`
2. Alembic 迁移并 upgrade
3. 建 `app/storage.py`:封装 R2(用 boto3,S3 兼容端点)
   - `upload_bytes(key, data, content_type) -> storage_key`
   - `presigned_get_url(key, expires) -> url`(供客户端显示图片)
4. 建 `app/imagegen.py`:封装生图 API
   - **先问用户用哪个生图服务**(Flux / 即梦 / DALL·E),不要擅自选
   - `generate(prompt) -> image_bytes`
5. 实现接口:

   | 方法 | 路径 | 说明 |
   |------|------|------|
   | GET | /scripts/{id}/images | 该脚本的图(附带每张的 presigned url) |
   | POST | /scripts/{id}/images/generate | {prompt, provider} → 生图 → 存 R2 → 建记录 → 返回记录+url |
   | DELETE | /images/{id} | 删记录(R2 文件可选删) |

6. storage_key 命名:`images/{script_id}/{uuid}.png`

## 验收标准
- POST generate 一个 prompt,返回图片记录 + 可访问的 presigned url(浏览器能打开看到图)
- GET images 能列出该脚本的图
- R2 bucket 里确实多了文件

## 注意
- 生图 API 会花钱,提醒用户
- 如果用户还没选生图服务或没 key,先停下来问,不要硬编码

把生成的图 url 给用户看,等确认再做 A4。
