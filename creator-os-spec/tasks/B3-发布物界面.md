# B3 · 发布物区域 + 数据曲线

## 目标
在脚本详情里加发布物区域:贴链接/传文件、看数据、手动回填、画增长曲线。
这是用户最想要的「每个脚本下挂发布追踪」功能。

## 前置
- B2 已通过验收
- 后端 A4(必须)、A5(可选)已跑通

## 要做的事
1. 脚本详情里加「发布物」区域:
   - 列出该脚本的发布物(GET /scripts/{id}/publications)
   - 每条显示:平台、类型、发布时间、最新数据摘要
2. 「添加发布物」表单:
   - 选 type(视频/图文)、platform(抖音/小红书/YouTube)
   - 选 source:
     - link → 填链接 → POST publications
     - upload → 先 POST upload-url 拿预签名 URL → 用 fetch/axios PUT 直传 R2 → 再建记录
3. 点某发布物看详情:
   - 数据时间序列曲线:用 **Recharts** 画 views/likes 随时间(前端已有 recharts 生态,AI 熟)
   - 「手动更新数据」表单 → POST metrics(抖音/小红书用)
   - YouTube 显示「自动追踪中」,数据由后端定时任务更新
4. 待更新提醒:列出 active 且很久没更新数据的发布物,提示回填

## 技术提示
- 装 recharts 画曲线
- 文件上传直传 R2:拿到预签名 PUT url 后,前端直接 PUT 文件字节,不经过后端

## 验收标准
- 加一个抖音链接发布物 → 出现在列表
- 手动填两次数据 → 曲线显示增长
- 加一个 YouTube 发布物 → 显示自动追踪状态
- 上传一个视频文件走 upload 流程 → R2 有文件、记录建成
