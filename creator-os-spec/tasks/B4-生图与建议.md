# B4 · 生图界面 + AI 建议台

## 目标
脚本配图工作流 + AI 建议界面,补齐最后两块能力。

## 前置
- B3 已通过验收
- 后端 A3(生图)已跑通;A6(学习层)跑通后建议台才有实质效果

## 要做的事
1. 生图区域(脚本详情里):
   - 输入 prompt → POST /scripts/{id}/images/generate → 显示生成的图
   - 已生成的图以网格显示(GET images,用 presigned url)
   - 图可点击放大(简单 modal)、可删除
   - 显示每张图的 prompt(方便复用/微调)
2. AI 建议台(左栏一个入口/独立路由):
   - 「优化当前脚本」→ POST /scripts/{id}/suggest → 显示建议
   - 「按选题生成新脚本」→ 输入选题 → POST /scripts/generate → 显示草稿 → 「存为新脚本」按钮
   - 若 A6 未做,显示「学习层未启用」占位
3. 加载/错误态:生图和 AI 调用慢,要有 loading spinner 和错误提示(TanStack Query 的 isPending/isError 直接用)

## 验收标准
- 输入 prompt 生成图 → 显示在脚本图库
- 图能放大、能删
- 建议台调 suggest → 返回建议文本
- generate 新脚本 → 能一键存为新脚本进列表

## 做完就停
核心功能全通。和用户过一遍完整链路:
建脚本 → 生图 → 发布挂链接 → 数据回填 → AI 建议。

## 后续(可选,产品化时再做)
- 用户认证(注册/登录),把单用户模式改成多用户
- 部署上线(前端 Vercel,后端 Railway)
