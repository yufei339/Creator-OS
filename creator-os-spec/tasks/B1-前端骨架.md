# B1 · React 前端骨架 + API 层

## 目标
建 React + TypeScript 工程,搭好和后端通信的 API 层,跑通一个真实接口,立起三栏布局。

## 前置
- 后端 A 部分已跑通,API 可访问(本地 http://localhost:8000 或已部署)
- 后端已开 CORS 允许前端地址

## 说明(用户是全栈背景,但 TS/React 未必精通)
- 代码清晰、适度注释,便于用户理解
- 用主流写法,别用冷门技巧;结构简单直接

## 技术栈
React + TypeScript + Vite,Tailwind CSS,TanStack Query,React Router

## 要做的事
1. 用 Vite 建工程:`npm create vite@latest frontend -- --template react-ts`
2. 装依赖:tailwindcss、@tanstack/react-query、react-router-dom、axios
3. 配 Tailwind(按官方 Vite 指引)
4. 建目录结构:
   ```
   frontend/src/
     api/          # 接口封装
       client.ts   # axios 实例,baseURL 从 .env 读
       scripts.ts  # 脚本相关请求函数
     types/        # TS 类型(对应后端返回)
     components/   # 通用组件
     pages/        # 页面
     App.tsx       # 三栏布局 + 路由
   ```
5. `client.ts`:axios 实例,baseURL 用 `import.meta.env.VITE_API_BASE`(建 .env:`VITE_API_BASE=http://localhost:8000`)
6. 配 TanStack Query 的 QueryClientProvider
7. 三栏布局(用 Tailwind flex/grid):左侧栏 / 中间内容 / 右侧检视器
8. 跑通验证:用 useQuery 调 `GET /scripts`,把脚本标题列在左栏(空列表也算通)

## 验收标准
- `npm run dev` 启动,浏览器打开无报错
- 三栏布局显示正常
- 成功调用后端 /scripts 并显示结果(空列表也行,证明通信+CORS 都通了)

把运行效果告诉用户,等确认再做 B2。
