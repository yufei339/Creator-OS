# B2 · 脚本列表 + 编辑器 + 版本

## 目标
完整的脚本管理界面:左栏列表、中间编辑器、右栏版本历史。

## 前置
- B1 已通过验收

## 要做的事
1. 左侧栏:
   - 脚本按 series 分组显示
   - 「新建脚本」按钮
   - 点击选中一个脚本(选中态存 URL 或全局 state)
2. 中间编辑器:
   - 显示选中脚本的 title + content,可编辑(textarea)
   - 状态下拉(draft/ready/shot/published)
   - 「保存」按钮 → PATCH /scripts/{id}
   - 「保存新版本」按钮 → 弹窗填 change_note → POST versions
3. 右侧检视器:
   - 版本历史列表(GET versions,倒序)
   - 每个版本可「回滚」→ POST restore → 编辑器内容刷新
4. 数据请求全用 TanStack Query:
   - useQuery 拉列表/详情/版本
   - useMutation 做增删改,成功后 invalidate 相关 query 自动刷新
5. 编辑防丢:内容有未保存改动时切换脚本,提示确认

## 验收标准
- 新建脚本 → 出现在左栏对应分组
- 编辑内容并保存 → 刷新页面仍在
- 存新版本 → 右栏版本列表出现
- 回滚版本 → 编辑器内容变回该版本
- 删除脚本 → 从列表消失
