# A2 · 脚本 CRUD + 版本 API

## 目标
实现脚本的增删改查,以及版本历史(存版本、回滚)。

## 前置
- A1 已通过验收(工程能跑、DB 连通、有固定 user)

## 要做的事
1. 建 ORM 模型:`scripts`、`script_versions`(对应 schema.sql)
2. Alembic 生成迁移并 upgrade
3. Pydantic schema:ScriptCreate / ScriptUpdate / ScriptOut / VersionCreate / VersionOut
4. 实现接口(单用户模式,user_id 用 A1 的固定值):

   | 方法 | 路径 | 说明 |
   |------|------|------|
   | GET | /scripts | 列表,支持 ?series= 过滤 |
   | POST | /scripts | 新建 {title, content, series, tags} |
   | GET | /scripts/{id} | 详情 |
   | PATCH | /scripts/{id} | 更新 {title, content, status, tags} |
   | DELETE | /scripts/{id} | 删除 |
   | GET | /scripts/{id}/versions | 版本列表(倒序) |
   | POST | /scripts/{id}/versions | 存新版本 {content, change_note} |
   | POST | /scripts/{id}/restore/{version_id} | 用某版本内容覆盖当前脚本 content |

5. PATCH 更新脚本时,自动刷新 updated_at
6. 说明:版本不是每次改都自动存,而是用户显式调用 POST versions 才存快照(客户端会有「保存新版本」按钮)

## 验收标准
用 curl 或 HTTPie 跑一遍完整流程,都成功:
- 新建脚本 → 拿到 id
- 改脚本内容 → GET 确认已变
- 存一个版本 → GET versions 看到它
- 再改内容 → restore 到刚才版本 → GET 确认 content 回滚了
- 删除脚本 → GET 返回 404
