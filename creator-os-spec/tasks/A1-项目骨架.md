# A1 · 项目骨架 + 数据库连接

## 目标
搭起 FastAPI 工程,连上 Postgres,能跑起来并通过健康检查。

## 前置
- 已读 README.md
- 用户已准备好 Postgres(本地或云),DATABASE_URL 在 .env

## 要做的事
1. 建工程结构:
   ```
   backend/
     app/
       main.py          # FastAPI 入口
       config.py        # 读环境变量
       db.py            # SQLAlchemy engine + session
       models/          # ORM 模型(本步先建 users)
       routers/         # 路由(本步先建 health)
     alembic/           # 迁移
     requirements.txt
     .env.example
   ```
2. `requirements.txt`:fastapi, uvicorn, sqlalchemy>=2.0, alembic, psycopg[binary], pgvector, python-dotenv, pydantic-settings
3. `config.py` 用 pydantic-settings 读 .env
4. `db.py` 建 engine + SessionLocal + get_db 依赖
5. 建 `users` ORM 模型(对应 schema.sql)
6. 配置 Alembic,生成首个迁移(建 users 表 + 启用 vector/pgcrypto 扩展)
7. `GET /health` 返回 `{"status":"ok"}` 且能连通数据库(执行 `SELECT 1`)
8. 写一个 `seed.py`:插入一个固定 user(固定 UUID,写进 README 供后续单用户模式用)

## 验收标准(完成的标志)
- `uvicorn app.main:app` 能启动无报错
- `alembic upgrade head` 成功建表
- 访问 `GET /health` 返回 ok,且数据库连接正常
- 运行 seed.py 后,users 表里有一条固定用户记录

## 做完就停
把启动方式、健康检查结果、固定 user_id 告诉用户,等确认再做 A2。
