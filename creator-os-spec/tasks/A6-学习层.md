# A6 · 学习层 · RAG 风格检索 + AI 建议(后置)

## 目标
基于历史高表现脚本 + 风格档案,让 Claude 给出剪辑/脚本建议。

## 前置
- A4/A5 已跑通,且**已积累一定数据**(至少十几条脚本 + 对应发布数据)
- 数据太少时本步效果有限,别急着做

## 重要:这是 RAG,不是微调
不训练模型。做法是:检索「和当前选题最像 + 数据表现最好」的历史脚本,拼上风格规则,塞进 Claude 的 prompt。

## 要做的事
1. 建 ORM 模型 `script_embeddings`、`style_profiles`
2. Alembic 迁移(注意 ivfflat 索引)
3. 建 `app/embeddings.py`:调 Claude/OpenAI embedding API 把脚本文本向量化
4. 脚本保存时(或批量任务)生成/更新其 embedding
5. 建 `app/style.py`:
   - 计算每个发布物的「表现分」(可简单加权:完播率 + 互动率)
   - 提取高表现脚本的共性,写入 style_profiles.rules(jsonb)
6. 实现接口:

   | 方法 | 路径 | 说明 |
   |------|------|------|
   | POST | /scripts/{id}/suggest | 对当前脚本给优化建议 |
   | POST | /scripts/generate | 按选题生成新脚本草稿 |

7. suggest/generate 的内部流程:
   - 把输入选题/脚本向量化
   - pgvector 检索最相似的 N 个高表现历史脚本
   - 取 style_profiles 的规则
   - 组装 prompt(历史成功案例 + 风格规则 + 当前请求)→ 调 Claude → 返回建议

## 验收标准
- suggest 一个已有脚本 → 返回的建议里能看出参考了历史高表现脚本的特征
- generate 一个新选题 → 产出符合你风格的草稿
- 检索确实命中了数据好的脚本(可打印检索到的是哪几条)
